# Tamimon

**Terminal Monster** — CLIで動作する育成放置ゲーム。閉じている間もモンスターが成長します。

## Tamimonとは？

Tamimonはデジモンやたまごっちにインスパイアされた、ターミナルベースの育成放置ゲームです。

- **放置OK** — アプリを閉じている間もリアル時間が経過し、ステータスが変化し、イベントが発生します
- **お世話をサボっても死なない** — ステータスが低くても死にません。死因は稀な「事故」のみ
- **ステータスは見えない** — きもち・げんき・なかよし度は一切表示されません。見える数値は体重だけ。状態はすべて表情とセリフで表現されます
- **育て方で進化が変わる** — アクションの傾向がコサイン類似度で評価され、120種以上の進化先が決まります。狙って出すのは難しい——それが面白さです
- **全種族ユニークなアスキーアート** — 気分変化やアクションアニメーション付き

## 機能

- 4段階の進化システム（たまご → Stage 1 → Stage 2 → Stage 3、+ レアなStage 4突然変異）
- 全ステージ合計120種以上のユニーク種族
- 12種類の口調タイプによる個性的なセリフ
- オフライン中のランダムイベント・事故
- 図鑑（アルバム）で育てたモンスターを記録
- WorldTimeAPIによる時刻検証（ローカルフォールバック付き）
- セーブデータは `~/.tamimon/save.json` にJSON保存

## インストール

### クイックインストール（macOS / Linux）

```bash
curl -sSL https://raw.githubusercontent.com/usagi-f/tamimon/main/install.sh | sh
```

インストール先を変更する場合：

```bash
TAMIMON_INSTALL_DIR=~/.local/bin curl -sSL https://raw.githubusercontent.com/usagi-f/tamimon/main/install.sh | sh
```

### ソースからビルド（Rust環境が必要）

```bash
cargo install --git https://github.com/usagi-f/tamimon.git
```

### バイナリダウンロード

[Releases](https://github.com/usagi-f/tamimon/releases) ページから各プラットフォーム向けビルド済みバイナリをダウンロードできます：

| プラットフォーム | バイナリ |
|--------------|--------|
| Linux (x86_64) | `tamimon-x86_64-unknown-linux-gnu` |
| macOS (Intel) | `tamimon-x86_64-apple-darwin` |
| macOS (Apple Silicon) | `tamimon-aarch64-apple-darwin` |

## 遊び方

```bash
tamimon
```

初回起動時にたまごの名前を決めます。約1時間後に孵化してStage 1のモンスターが生まれます。

### アクション

| キー | アクション | 効果 |
|-----|----------|------|
| `T` | 話しかける | なかよし度・きもちUP |
| `P` | あそぶ | きもち・げんきUP |
| `R` | 特訓 | げんきUP・体重ダウン |
| `E` | まったり | きもちUP・体重アップ |
| `A` | 図鑑 | モンスターコレクションを見る |
| `Q` | 終了 | セーブして終了 |

クールタイムはありません。いつでも何度でもアクションできます。

### 進化

モンスターの進化は育て方によって決まります：

- **Stage 1**（約1時間後）：たまごからランダムに決定
- **Stage 2**（約6時間後）：アクション傾向で決定
- **Stage 3**（約24時間後）：育成ベクトルのコサイン類似度で決定
- **Stage 4**（レア突然変異）：24時間ごとに25%の確率で判定

進化タイプは **ちから**・**おだやか**・**ぼうけん**・**ノーマル**・**ワイルド** の5種類です。

### 死亡と再スタート

モンスターの死因はランダムな事故のみ。ステータスが低くても死にません。死亡したモンスターは図鑑に記録され、新しいたまごから再スタートします。

なかよし度が高いほど事故からの生還確率が上がります。
